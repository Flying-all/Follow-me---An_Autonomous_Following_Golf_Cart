Follow Me 自主跟随高尔夫球车仓库解读

这个仓库描述的是一个基于 UWB 定位、树莓派 GPIO 和原车遥控器按键接口的“自主跟随高尔夫球车”方案。它的核心不是完整工程化代码包，而是一份算法/控制方案加一段原型 Python 程序。

UWB 定位 自适应卡尔曼滤波 预测前馈控制 GPIO 脉冲控制

一句话概括

项目用 UWB 模块测量人与球车的角度和距离，经过滤波、预测和控制策略计算后，由树莓派模拟遥控器按键，让电动高尔夫球车保持合适距离并朝目标方向移动。

系统工作流程

1. UWB 获取目标位置：读取目标相对于球车的角度和距离，串口默认是 /dev/ttyS0、115200 波特率。
2. 角度滤波：用自适应卡尔曼滤波器平滑 UWB 角度数据，并处理突变或噪声。
3. 未来位置预测：根据历史角度估计角速度、角加速度，补偿系统延迟。
4. 控制强度计算：结合距离、角度大小、是否收敛、转向速度等因素，决定动作频率。
5. GPIO 模拟遥控器：树莓派通过 GPIO 触发前进、左转、右转、停止按键，实现对原车的间接控制。

核心模块解读

UWBReader

负责串口读取 UWB 数据包，校验起止标记，解析地址、角度和距离。解析后的角度会先进入卡尔曼滤波器，再提供给控制主循环。

AdaptiveKalmanFilter

状态量为 [角度, 角速度]。它通过预测和更新两步降低 UWB 噪声影响，并在检测到角度突变时动态调整观测噪声。

PredictiveController

保存最近的角度、距离和时间序列，估算角速度/角加速度，然后预测短时间后的角度，用来弥补传感器、算法和机械响应的延迟。

AdaptiveSpeedController

把“控制强度”转换成前进或转向脉冲间隔。控制因子越小，脉冲间隔越大，动作越保守。

MotorController

定义 GPIO 引脚并模拟按键。默认引脚为前进 18、左转 23、右转 24、停止 25。

main 主循环

启动 UWB 读取线程，每 0.1 秒检查一次数据。如果数据新鲜就控制电机，如果超过 1 秒没有有效数据就触发停止。

控制策略

场景 行为
距离大于等于 2.5 米 优先追赶；如果角度偏差明显则转向，否则发送前进脉冲。
距离小于等于 1.5 米 立即停止，避免撞上跟随目标。
距离在 1.5 米到 2.5 米之间 谨慎模式，转向和前进脉冲更保守。
角度绝对值较大 增加转向动作频率；角度较小时降低动作频率，避免来回摆动。
预测显示角度正在收敛 降低控制强度，减少过冲。

硬件与依赖

  • 主控：Raspberry Pi 4 或类似可运行 Python、支持 GPIO 和串口的设备。
  • 定位：UWB 模块，文档中提到 DW1000，串口数据包长度为 31 字节。
  • 执行机构：通过原车遥控器按键触点接入，而不是直接驱动电机控制器。
  • Python 依赖：numpy、pyserial、RPi.GPIO。

当前仓库状态判断

这个仓库更像“方案说明 + 原型代码存档”，还不是可以直接部署的规范 Python 项目。主要原因是：源码放在 .txt 文件中，多个 Markdown 文件存在编码乱码，缺少启动脚本、测试、配置样例和硬件接线图。

如果要继续工程化，建议先把 docs/follow me-跟隨球袋車.txt 整理为正式的 .py 源码，再补充硬件接线说明、UWB 数据格式说明、参数配置文件和模拟数据测试。

适合怎么理解这个项目

它的价值主要在控制思路：用 UWB 得到“人在哪里”，用滤波和预测解决“数据抖、响应慢”的问题，再用 GPIO 脉冲把连续控制意图转换成遥控器能理解的离散按键动作。换句话说，它是在不深度改造原车电控系统的前提下，为电动高尔夫球车加上自主跟随能力。
